\# 🇬🇧 English



\## 📌 About



\*\*Multilingual WPF Calculator\*\* is a simple Windows desktop calculator created with C# and Windows Presentation Foundation (WPF).



The application was developed as \*\*Day 002 of my 365 Days of Code challenge\*\*.



The main goal of this project was to practice WPF application development, XAML interfaces, C# event handling and multilingual user interfaces.



\## 🌐 Supported Languages



The interface can be switched between:



\- 🇬🇧 English

\- 🇰🇿 Қазақша

\- 🇷🇺 Русский



The language can be changed directly inside the application.



\## 🧮 Operations



The calculator supports:



\- Addition

\- Subtraction

\- Multiplication

\- Division



It also supports decimal numbers and prevents division by zero.



\## 📥 Download



You don't need Visual Studio to use the compiled version.



Open the \*\*Releases\*\* section of this repository and download:



`Multilingual-WPF-Calculator-v1.0.0-win-x64.zip`



Then:



1\. Extract the ZIP archive.

2\. Open the extracted folder.

3\. Run `MultilingualCalculator.exe`.



> Windows x64 is required for the current release.

\# 🚀 Run from Source



\## Requirements



\- Windows 10/11

\- Visual Studio

\- .NET

\- WPF development workload



Clone the repository:



```bash

git clone https://github.com/mnerst1/Multilingual-WPF-Calculator.git

```



Open the project in Visual Studio and press:



```text

F5

```



or run:



```bash

dotnet run

```



\---



\# 📦 Build Release



To create a Windows x64 self-contained build:



```bash

dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true

```



The published application will be located inside:



```text

bin/Release/net10.0-windows/win-x64/publish/

```
